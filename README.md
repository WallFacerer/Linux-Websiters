# Linux Website

Een moderne, responsive website over Linux - gemaakt als schoolproject voor SALCO 2026.

## Features

- **Dark Cyberpunk Design** - Cyaan accenten met diepe blauwe tinten
- **Volledig Responsive** - Werkt op desktop, tablet en mobiel
- **Scroll Animaties** - Elementen verschijnen vloeiend bij scrollen
- **Mobile Menu** - Hamburger menu voor mobiele apparaten
- **Contact Formulier** - Met client-side validatie
- **Meerdere Pagina's** - Home en Over pagina's

## Pagina's

- `index.html` - Hoofdpagina met alle secties
- `about.html` - Gedetailleerde informatie over Linux
- `style.css` - Complete stylesheet met CSS variabelen
- `index.js` - Interactiviteit en animaties

## Technologieën

- HTML5 (semantisch)
- CSS3 (custom properties, grid, flexbox, animaties)
- Vanilla JavaScript (ES6+)
- Intersection Observer API

## Ontwikkeling

Open `index.html` in je browser om de website te bekijken. Geen build-proces nodig!
